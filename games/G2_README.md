# G2. 청개구리 퀴즈 🐸

**Python + Streamlit | G2-A/B 통합 | 테스트용 의도적 버그 1개**

## 기능
- **G2-A:** 지시대로는 문장의 참/거짓 그대로 O/X, 반대로는 뒤집어서 O/X 선택
- **G2-B:** 총 3문항, 정답 1개당 1점. **3점이면 `complete_game("G2")`** 처리
- 오답 시 재도전 가능. 재시작하면 G2 점수·답안·완료 상태 초기화
- `games/g2.py`의 `render()`를 기존 `app.py`가 호출 (`core/state.py` 수정 불필요)

## 실행
```powershell
python -m streamlit run app.py
```
왼쪽 메뉴에서 **G2**를 선택한다.

## 🐛 의도적 버그: 반대로 + 거짓(X) 문항 채점

**기대:** 반대로 지시가 붙은 *거짓(X)* 문항은 **O**를 선택해야 정답.

**재현:**
1. G2에서 1번은 **O**, 2번은 **X**, 3번은 **O**를 선택하고 채점한다.
2. **기대:** 3점 만점, G2 완료.
3. **실제:** 3번을 오답 처리하여 **2점**이 나온다.
4. 다시 시작한 뒤 **O / X / X**로 제출하면 3점이 나온다. (원래 규칙과 다름)

**원인:** `expected_answer()`가 `반대로` + 참(O)만 X로 바꾸고, `반대로` + 거짓(X)은 O로 바꾸지 않는다.

<details><summary>수정 힌트 (테스트 후 확인)</summary>

`games/g2.py`의 `expected_answer()`를 다음처럼 고친다.

```python
if question["mode"] == "반대로":
    return "X" if answer == "O" else "O"
return answer
```
</details>

## 간단 테스트

| 입력 (1/2/3번) | 기대 점수 | 버그 포함 버전 |
|---|---:|---:|
| O / X / O | 3 | **2** |
| O / X / X | 2 | **3** |
| O / O / O | 2 | 1 |

> 학습용 의도적 결함이며, 공통 `app.py`·`core/state.py`가 아니라 **G2 모듈만** 수정·PR하면 된다.
